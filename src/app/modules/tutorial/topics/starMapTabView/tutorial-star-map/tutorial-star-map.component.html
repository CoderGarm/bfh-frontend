The shown system details are displaying next to the amount of planets in the system also the cartesian coordinates in the galaxy.

Fleets on the map

A fleet which enters a star system from the hyperspace will stay at the hyper limit.
It's kind of a gravitational barrier which doesn't allow transitions from or to hyper bands.

If a fleet has entered the system you can select it by clicking on them and select a movement target, too.
Currently only planets can be a movement target.

Fleet actions

Fleet can be execute several actions beside their function as police forces in case of pirate attacks.

Transports

A fleet with cargo space or room for passengers can move their 'load' everywhere. Use the transport dialog to fill the remaining space and move the fleet to their destination.

Split and merge fleets

Fleet can be merged by selecting multiple fleets in the same orbit and opening the Transfer dialog. There the single ships can be dragged between fleets.

Splitting a fleet is currently only possible in the fleet menu -> Detachment.
